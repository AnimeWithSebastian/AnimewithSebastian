# Law Audit — 2026-08-14

Full line-by-line pass over all 62 files in `laws/` (6,689 lines), cross-checked against
`validators/validate_dual_package.py`, `tools/`, `cron_daily_runtime.txt`, and
`docs/PROJECT_HANDOFF.md`.

Authority order used throughout, per PROJECT_HANDOFF §2: **(1) running
runtimes/validators → (2) newest numbered law → (3) master laws file → (4)
templates/docs → (5) older language.** Where a law file disagreed with shipped code,
the code was treated as correct and the law text was marked, not the reverse.

**Result: 24 issues found. 14 fixed. 10 flagged for your decision.**

Every fix is additive — a dated correction banner or a superseded marker. No original
law text was deleted or silently rewritten, per the project's standing
no-retroactive-rewrite rule. The one exception is the code fix in item 1, which had to
change a real assertion.

reduced. **Suite now passes: 463 tests, 48 subtests, zero failures.**
